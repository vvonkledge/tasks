# pi-agent-tasks

A [pi package](https://pi.dev) for agent-tasks: agent task manager where one orchestrator writes and minions report.

Generated by `tasks.py pi-package`. Do not edit by hand - regenerate instead.
`tasks.py pi-package --check` catches drift, but only on the machine that
generated the package: the absolute fallback path below is baked in at
generation time, so the check fails anywhere else. In CI, check the skill
instead - it carries no machine-specific paths.

## Install

```sh
pi install /path/to/pi-agent-tasks
```

Add `-l` to install into this project's `.pi/settings.json` instead of your
account.

## What it provides

- **skills/agent-tasks/SKILL.md** - loaded on demand when a task involves
  queueing, dispatching, or verifying work for a fleet of agents.
- **extensions/ambient-context.ts** - captures the queue at `session_start` and
  appends it to the system prompt, so a session opens already knowing what is in
  flight, what is ready, and what is stuck.

The extension shells out to `tasks` if it is on `PATH`, otherwise to the
absolute path baked in when this package was generated:

```
tasks --ambient
```

For the package to work on another machine, install `tasks` on `PATH`
there. Otherwise regenerate the package on that machine.

In a directory with no task store the command prints nothing, and the extension
leaves the system prompt untouched.
